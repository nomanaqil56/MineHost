# MineHost — Build & Installation Guide

## 1. Prerequisites

To build MineHost from source, ensure you have:
- **Operating System:** Windows 10/11, macOS, or Linux (Ubuntu 20.04+).
- **JDK:** OpenJDK 17 or 21 (Temurin, Zulu, or Microsoft OpenJDK).
- **Android SDK:**
  - Android SDK Platform 34 (Android 14) or 35.
  - Android SDK Build-Tools 34.0.0+.
  - Android NDK 26.x+ (if compiling custom JNI libraries).
- **Gradle:** Gradle 8.4+ (or bundled Gradle wrapper `./gradlew`).
- **Android Device / Emulator:**
  - Physical Android 9.0+ device (ARM64 recommended) with USB Debugging enabled, OR
  - Android Studio Emulator (API 30+ ARM64 / x86_64).

---

## 2. Project Build Commands

### 2.1 Building the Debug APK
```bash
# On Linux / macOS
./gradlew assembleDebug

# On Windows PowerShell
.\gradlew.bat assembleDebug
```
The resulting debug APK is generated at:
`app/build/outputs/apk/debug/app-debug.apk`

### 2.2 Running Unit Tests
```bash
./gradlew testDebugUnitTest
```

### 2.3 Running Android Instrumentation Tests
Ensure a device or emulator is connected via ADB (`adb devices`):
```bash
./gradlew connectedDebugAndroidTest
```

### 2.4 Installing Directly onto a Connected Device
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 3. Project Configuration

### 3.1 `local.properties` Setup
Create `local.properties` in the project root if not auto-generated by Android Studio:
```properties
sdk.dir=C\:\\Users\\<YourUsername>\\AppData\\Local\\Android\\Sdk
# Or on Linux:
# sdk.dir=/home/<username>/Android/Sdk
```

### 3.2 Native Binaries Packaging
MineHost packages native binaries in `app/src/main/jniLibs/<abi>/lib<name>.so`:
- `arm64-v8a`:
  - `libplayit.so`
  - `libserverlauncher.so`
- `x86_64` (for emulator testing):
  - `libplayit.so`
  - `libserverlauncher.so`
