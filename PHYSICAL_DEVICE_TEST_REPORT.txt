1. CRITICAL DISCOVERIES & ROOT-CAUSE BUG FIXES
--------------------------------------------------------------------------------
1. The 300-Character Truncation Bug (RuntimeManager.kt:411):
   - Previous tests falsely reported missing extensions: sockets, yaml, zip, zlib, webrtc.
   - Root cause: RuntimeManager.kt used .take(300) when reading process stdout,
     chopping off php -m output alphabetically at letter 'S'.
   - Fix: Increased buffer limit to take(64 * 1024), fully capturing all extensions.
   - Added TMPDIR and LD_LIBRARY_PATH environment variables to ProcessBuilder.

2. Android 16 Foreground Service Startup Crash (ServerForegroundService.kt):
   - Starting a server threw ForegroundServiceDidNotStartInTimeException because
     ServerForegroundService lacked onCreate() and only promoted in onStartCommand.
   - Fix: Implemented onCreate() to immediately call promoteToForeground(),
     and re-sequenced ServerController to spawn the process handle before
     requesting the foreground service.
